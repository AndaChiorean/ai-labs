## QUICK CONVERSION CHART (writing answers)

If your exam is in Romanian but you only know it in English:

- "It learns by gradient descent" → *Învață prin metoda gradientului descendent*
- "The neural network has 3 layers" → *Rețeaua neuronală are 3 straturi*
- "The algorithm has complexity O(n²)" → *Algoritmul are complexitatea O(n²)*
- "A decision tree splits on the attribute with maximum information gain" → *Un arbore de decizie se ramifică pe atributul cu câștig informațional maxim*
- "The perceptron cannot learn XOR because XOR is not linearly separable" → *Perceptronul nu poate învăța XOR pentru că XOR nu este liniar separabil*
